## Запуск

```bash
npm install
npm run dev
```

## Перевірка

- Пошук, фільтр, пагінація та розмір сторінки зберігаються в URL.
- Кнопка **Add user & wallet** створює запис.
- Кнопка **Edit** редагує користувача й гаманець.
- Щоб перевірити помилку 500, вкажіть у полі **Address** значення `500`.
- Дані мокові та знаходяться в `src/data/`.
